# Changelog

- renamed the skill to `qa-auditor`;
- made autonomous rule discovery mandatory in every operation mode;
- removed domain-skill dependency semantics;
- added Independent, Integrated and Hybrid operation modes;
- added optional `domain_rules` configuration with `auto` as default;
- added compare-and-consolidate source handling;
- added rule classification, source conflicts and domain-gap artifacts;
- added QA, imported, consolidated and critical coverage metrics;
- changed confidence to evidence-based calculation;
- preserved read-only behavior and all previous technical QA coverage;
- kept the prioritized bug table as the primary output.
